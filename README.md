# Учебное задание 7: Автоматический кредитный скоринг

### Цель 

Добавить в credit-service систему автоматического одобрения кредитов на основе запроса, данных пользователя.

---

## 📌 **Функциональность**
- на основе алгоритма, либо бизнес правила по заявке пользователя система должна автоматически одобрить, либо отклонить заявку на кредит
- система должна учитывать добросовестные платежи пользователей, получая их из Loan Management Service
- система должна вычислять результат заявки на кредит минимум из 3-х правил
- после автоматического одобрения заявки, либо одобрения кредитным менеджером, должен вызываться loan-management-service для пополнения кредитного счёта пользователя
- по изменению статуса пользователю должна присылаться нотификация
---
